# Prompt 01 — Planificación inicial

## Instrucción entregada al agente

Lee completamente `AGENTS.md` y `RULES.md`.

Analiza el proyecto GarageLink y plantea un plan mínimo para construir:

- Una pantalla de bienvenida personalizada.
- Una pantalla de login interactiva.
- Navegación mediante estado local.
- Validaciones de correo y contraseña.
- Feedback visual de éxito.

No escribas código todavía.

Indica:

- Archivos necesarios.
- Componentes requeridos.
- Estados que utilizarás.
- Flujo entre pantallas.
- Validaciones.
- Decisiones visuales.
- Forma de verificar el resultado.

Prioriza una solución fácil de comprender, probar y explicar.
